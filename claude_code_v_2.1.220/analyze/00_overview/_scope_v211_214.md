# Changelog scoping + anchor probe: 2.1.211-2.1.214

Three releases, **132 bullets** (`.211`=37, `.212`=48, `.214`=47; `.213` was never published). This is the
security-and-plumbing core of the whole 193→220 window. Two things dominate: (a) a **Bash/PowerShell
permission-analyzer hardening sweep** in `.214` — six consecutive bullets, all of which land in the
`too-complex`/`passthrough` reason tables of the shell parser and the read-only flag allowlists, and all of
which are cleanly net-new string literals; and (b) a **background-daemon/roster lifecycle overhaul** spread
across all three versions (respawn suppression, adopt/handoff, worktree deletion, control-socket takeover),
which is where most of the 326 new `tengu_bg_*` / `tengu_adopt_*` gates live. `.212` is the feature-heavy
one: `/fork`-as-background-session (with `/subtask` splitting off the old in-session behaviour), three new
per-session budget env vars, MCP auto-backgrounding, and a four-bullet `/ultrareview` precondition-recovery
subsystem (13 new telemetry call sites). `.211` is almost entirely bugfixes and is the weakest-anchored of
the three: several of its UI/Chrome/VSCode bullets have no CLI-side literal at all. Verdict counts across
the range: **84 NET_NEW / 22 DELTA / 10 CARRYOVER / 16 UNANCHORED**; depth **46 RICH / 56 MODERATE / 30 THIN**.
Zero bullets in this range are purely server-side — the two release-note/doc bullets (`.211`#30, `.212`#48)
are the closest, and even `.211`#30 is provable in the bundle.

Bundles: `T` = `2.1.220/extract/cli_inner_pretty.js`, `B` = `2.1.193/extract/cli_inner_pretty.js`.
All `Best 220 line` values were opened in the 2.1.220 bundle (via `Read` or `grep -n` with content shown).
"220"/"193" columns are `grep -cF` counts of the literal in the *Anchor probed* column (first literal when
several are listed).

### Notes — 2.1.211

- **Richest findings**: `hookAskFloor` (400915 + 513734) is a genuinely new two-stage decision floor — a hook
  `ask` is carried through the full permission pipeline as `{...ctx, hookAskFloor: true}` so that a later
  classifier `allow` "re-surfaces as this ask". The log string at 400915 spells the design out verbatim.
  Second: the OAuth *lock-compromised* family (5 new gates at 155345-155395) implements compare-and-swap on
  the refresh token so a session whose lock timed out adopts a sibling's rotated token instead of
  invalidating it — that is the actual "parallel sessions all log out" fix.
- **`canonical repo root` (224977) is the sleeper**: it resolves `localSettings` to the git repo root and
  *refuses* to copy `settings.local.json` into a worktree, because a copy "would become a stale,
  revocation-resurrecting legacy overlay". That single comment explains bullet 31 completely and is the best
  anchor in this version.
- **CARRYOVER traps (bullet reads new, literal is not)**: #19 (`resetCost`/`totalCostUsd` 1/1 — nothing about
  cost accounting changed at the literal level), #20 (`openInBrowser` 3/3), #22 (the refusal-detector regex
  `yLb`/193's equivalent is byte-identical), #26 (`writableLength` 6/6, `syncOutput` 3/3).
- **UNANCHORED (8)**: #5 (tried `reconnectPlugin`, `pluginMcp`, `idleWake`, `onWake`, `resumeFromIdle`,
  `ensureConnected`), #6 (`Falling back to`, `fallbackNotice`, `spurious fallback`), #11 (`shortcuts panel`,
  `toggleShortcuts`, `showShortcuts`), #13 (`delay: 300`, `loadingDelay`), #24 (`nextRun`, `nextRunAt`,
  `scheduleNextRun`, `year 1`), #26 (umbrella), #29 (`scientific notation`, `parseIntegerEnv`, `readIntEnv`,
  `64_000`), #33 (`case "S":`, `case "s":`, `case "D":`, `case "O":`, `"dd"`, `vimMode`, `substitute`),
  #34 (VS Code extension string, out of bundle).
- **Surprise**: `docs.claude.com` went to **zero** in 220 while `code.claude.com` gained 35 URLs — the doc-link
  bullet is a verifiable removal, not just cosmetic.
- **Weakest anchor**: #2. The bidi/zero-width/quote-lookalike regex family really did triple (3→10 sites), but
  the one site I could read end-to-end (`gxd`/`mxd`/`hxd` at 411808-411817, used at 411416-411438) guards
  **ClaudeDesign project names**, not the chat-relay permission preview. Recorded as DELTA, not NET_NEW.
