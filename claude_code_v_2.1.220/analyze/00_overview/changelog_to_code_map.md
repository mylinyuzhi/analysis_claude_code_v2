**Provenance.** Mechanically consolidated from the 25 per-release ledgers in
[`../by_version/`](../by_version/), which are the authoritative sources — each row there was written
by an agent that re-read the cited line in the 2.1.220 bundle, and every ledger was verified against

## 1. How to read a verdict

| Verdict | Meaning |
|---|---|
| `NET_NEW` | The mechanism is new in this window. Proven by `220>0 / 193=0` on a stable literal, with the 2.1.220 site read. |
| `DELTA` | The mechanism pre-existed; this release changed it. The narrower true change is named in the anchor column. |
| `CARRYOVER` | The headline literal already exists in 2.1.193. The bullet over-claims; writing it up as an introduction is a defect. |
| `GATE_REMOVAL` | A default flipped on, which *deletes* gating code. The literal count goes **down**. |
| `SERVER_SIDE` | Behaviour is controlled outside the client bundle (feature gate, org policy, API). |
| `UNANCHORED` | No client-side anchor was found. Candidates that were eliminated are named in the source ledger. |
