# Changelog scoping + anchor probe: 2.1.195-2.1.199

**Provenance document.** Every `220=N / 193=M` pair below is a `grep -c -F` count I ran against
`/lyz/codespace/claude-code-bomb/versions/2.1.220/extract/cli_inner_pretty.js` (TARGET) and
`/lyz/codespace/claude-code-bomb/versions/2.1.193/extract/cli_inner_pretty.js` (BASELINE) in this session.
Every `cli_inner_pretty.js:<line>` in the "Best 220 line" column is a line I read in the **2.1.220** bundle.
Baseline citations are tagged `(193)`.

**Shape of these five releases.** This is the *opening* of the 2.1.220 window and it is dominated by two
things: (1) the **Sonnet 5 launch** (`.197`, a single-bullet model release that lands a 1M-native default
model), and (2) an enormous **background-agent hardening push** — `.195`/`.196`/`.198`/`.199` together carry
~30 bullets about the bg daemon, roster, worker respawn, launcher, and the `claude agents` view. The second
theme is **subagent-as-background-default** (`.198`), which drags along thinking-config inheritance, the
Explore-agent model change, partial-result recovery on API errors (`.199`), and a rewritten shipping prompt
that makes bg agents open draft PRs. `.196` is the "org default model + reliability" release; `.199` is
almost entirely bugfixes but contains three of the richest single deltas in the whole window
(hook-matcher exact-match, stacked slash-skills, and the retry-watchdog constants).

Bullet counts as they actually appear in `CHANGELOG.md`: **.195=11** (the tree-level `_CONVENTIONS.md`
says 12 — I count 11 lines, `CHANGELOG.md:644-654`), **.196=27**, **.197=1**, **.198=33**, **.199=24** →
**96 bullets** in this range.

### Notes

- **Bullet 2 is the single best find in `.195` and possibly the whole range.** The 2.1.220 bundle contains a
  self-documenting warning: `Hook matcher \`${n}\` matches no tool (it is compared as an exact string). To
  match all tools from this server, use \`${n}__.*\`. See CHANGELOG v2.1.195.` at
  `cli_inner_pretty.js:520215` (220=1/193=0). The actual behaviour change is one character: the matcher
  fast-path char class went from `/^[a-zA-Z0-9_|, ]+$/` (`cli_inner_pretty.js:589636 (193)`) to
  `/^[a-zA-Z0-9_|, -]+$/` (`cli_inner_pretty.js:520221`). Adding `-` routes hyphenated matchers into the
  *exact-string* branch (`.split().map(trim).flatMap(expand).includes(name)`) instead of `new RegExp(t)`.
  A whole helper (`cli_inner_pretty.js:520204-520218`) was added just to warn when a hyphenated matcher
  now matches nothing.
- **The voice/audio bullets are the weakest anchors in the range.** `startNativeRecording` /
  `isNativeRecordingActive` are 220=2/193=2 — the macOS default-input-device fix lives in the native audio
  addon, not the JS bundle. The Linux one *is* anchorable: the "no microphone" branch at
  `cli_inner_pretty.js:496025-496027` is new text (220=1/193=0) sitting next to the pre-existing
  "requires SoX" branch (`:496016-496020`).
- **CARRYOVER trap in bullet 6/5:** `plugin.json` is 220=60/193=52 and `marketplace` is 220=855/193=816.
  Both literals are massively pre-existing; do not treat any plugin-name-resolution code as new without
  diffing the specific resolver.
- **`tengu_left_arrow_gesture` disappeared and `tengu_left_arrow_editing_guard` appeared** (193=2→220=0 and
  193=0→220=1, `cli_inner_pretty.js:559928`). That pairs with `.196`'s single-`←` bullet, not `.195`.
