# `by_version/` — Per-Release Breadth Index (v2.1.183 → v2.1.193)

This directory holds one **breadth** analysis file per published release in the **v2.1.183 → v2.1.193** window. Each `2.1.NN.md` is a faithful, source-cross-validated pass over *everything that release shipped* — new capabilities, hardened behavior, notable fixes, or an explicit no-isolable-surface finding — across **all** subsystems it touched (permissions/auto-mode, MCP, background & subagent lifecycle, telemetry, workflow/structured-output, agent team, skills, tools/CLI input, slash commands & plugins, …), with each item resolved to a `cli_inner_pretty.js:<line>` anchor in the **2.1.193** bundle where the changelog names a grep-able surface.

> **How to read this tree.** Three layers, each answering a different question:
> - **`by_version/` (here) = BREADTH.** "What did release X ship, across *all* subsystems?" One file per published release, including the .185 one-line streaming UX patch and the .190 no-isolable-surface maintenance placeholder.
> - **The twelve module dirs = DEPTH.** "How does *this one feature* work, fully deobfuscated?" → [`../38_permissions/`](../38_permissions/), [`../36_background_agents/`](../36_background_agents/), [`../39_mcp/`](../39_mcp/), [`../44_telemetry/`](../44_telemetry/), [`../42_workflow/`](../42_workflow/), [`../30_agent_team/`](../30_agent_team/), [`../45_skills/`](../45_skills/), [`../04_tools/`](../04_tools/), [`../43_slash_commands/`](../43_slash_commands/), [`../40_system_prompt/`](../40_system_prompt/), [`../31_auto_memory/`](../31_auto_memory/), [`../07_compact/`](../07_compact/).
> - **[`../00_overview/changelog_to_code_map.md`](../00_overview/changelog_to_code_map.md) = PER-BULLET POINTERS.** "Where is the exact patch line for *this one changelog bullet*, and what's out of scope this version?"
>
> When a by_version item touches one of the twelve depth themes, it gives a **short summary + the verified anchor + a link to the depth module** rather than re-deriving the mechanism. Non-theme items get their **primary analysis** in the by_version file itself.

## Window facts

- **Version span:** 2.1.184 … 2.1.193 — 10 version numbers, **6 published releases** (.185, .186, .187, .190, .191, .193).
- **Never published** (absent from the upstream [`../../CHANGELOG.md`](../../CHANGELOG.md), no public release notes): **.184, .188, .189, .192** — 4 numbers, no file.
- **Bug-fix placeholder:** **.190** ships a single boilerplate line ("Bug fixes and reliability improvements") with no enumerated bullets and no mappable in-scope delta. It has a dedicated breadth file, [`2.1.190.md`](./2.1.190.md), documenting the no-isolable-surface finding and bundle-provenance limits.
- **One-line reliability patch:** **.185** is a single bullet — the stream-stall hint reworded to "Waiting for API response · will retry in …" and re-timed from 10 s → 20 s of silence. It has a dedicated breadth file, [`2.1.185.md`](./2.1.185.md), but touches none of the twelve depth themes.
- **Files present here:** [`2.1.185.md`](./2.1.185.md), [`2.1.186.md`](./2.1.186.md), [`2.1.187.md`](./2.1.187.md), [`2.1.190.md`](./2.1.190.md), [`2.1.191.md`](./2.1.191.md), [`2.1.193.md`](./2.1.193.md) — all six published releases in the window.
- **Source bundle (TARGET):** `/lyz/codespace/claude-code-bomb/versions/2.1.193/extract/cli_inner_pretty.js` — **718,679 lines**, build SHA `a1938d2a…`, build_time **2026-06-25**, Bun 1.4.0. Because the bundle is the 2.1.193 *result*, earlier in-scope behaviors appear in their cumulative post-2.1.193 form. Lines tagged **(183)** are deliberate before-pictures read in `/lyz/codespace/claude-code-bomb/versions/2.1.183/extract/cli_inner_pretty.js` (699,346 lines, build `9d251abd…`, 2026-06-18); a deeper baseline (156) is `/lyz/codespace/claude-code-bomb/versions/2.1.156/extract/cli_inner_pretty.js`. The bundle grew ~19,300 lines across the window.
- **Re-mangling discipline:** obfuscated names are **re-minified between builds** and were re-derived per anchor in the 2.1.193 bundle — no 183/156 token was carried over by assumption. (Canonical trap: `$Cr` was `isSubagent` in 183 but is `isClassifyAllShellEnabled` in 193 — same token, different meaning. Always resolve by line, never by token across versions.)

### The four inflection points

1. **2.1.186 — the reliability + MCP-CLI watershed.** The densest release (33 items). It adds the non-interactive `claude mcp login`/`logout` CLI (auth a server without the `/mcp` menu, with `--no-browser` stdin redirect for SSH), makes `!` bash commands **auto-trigger a model response** (`respondToBashCommands`, default-on — an upgrade-behavior change), closes a long tail of background-agent panel/UX bugs, hoists `Agent(type)` deny / `Agent(x,y)` allow-list enforcement to the named-spawn site, caps the workflow `agent({schema})` retry loop at 5 attempts, makes skills frontmatter case-tolerant, and gracefully loads malformed `SKILL.md` YAML. Most of this window's *new capabilities* land here. → [`./2.1.186.md`](./2.1.186.md)
2. **2.1.187 — permissions + subagent-depth correctness.** `sandbox.credentials` blocks reading credential files / unsets secret env. Org entitlement model restrictions reach the picker, `--model`, `/model`, and `ANTHROPIC_MODEL`. **Subagent depth tracking is corrected** so resumed subagents restore their original spawn depth and **forked** subagents count toward the 5-level cap — a direct continuation of the v2.1.172/.181 nested-subagent work in the 183 tree. The remote MCP tool-call idle-timeout abort and stop attribution (`killedBy`) land here too. → [`./2.1.187.md`](./2.1.187.md)
3. **2.1.191 — MCP reliability + streaming perf + `/rewind`.** Capability discovery, OAuth, and token requests all gain retry/backoff; streaming CPU drops **~37%** by coalescing text updates to 100 ms; `/rewind` learns to resume from *before* `/clear`; the Recently-denied approve persists on close; stopping a bg agent becomes permanent; sandbox network "Yes" hosts are remembered for the session; the `"Bash,PowerShell"` hooks comma matcher finally fires. → [`./2.1.191.md`](./2.1.191.md)
4. **2.1.193 — auto-mode safety surfacing + telemetry.** `autoMode.classifyAllShell` routes *all* Bash/PowerShell through the auto-mode classifier (not just arbitrary-code patterns); auto-mode denial reasons now reach the transcript, the toast, and `/permissions`; the `claude_code.assistant_response` OTEL event ships (with the `OTEL_LOG_USER_PROMPTS` inheritance gotcha); idle bg shells are reaped under memory pressure; MCP `headersHelper` self-heals on 401/403; plugin marketplace `renames` are auto-followed. → [`./2.1.193.md`](./2.1.193.md)

The maturation framing is exact: every feature touched in this window was *introduced in or before 2.1.183*. This window **hardens the autonomy surface already shipped** rather than launching new subsystems — the prior window's [`changelog_analysis`](../00_overview/changelog_analysis.md) introduced whole features (implicit agent team, `ultracode`, nested subagents); this one makes them trustworthy enough to lean on harder.

> **Window-silent depth themes — present as dirs, absent from the changelog:** **CMP** changed only by a *behavior-preserving* internal refactor (the auto-compact dispatcher's flat `{wasCompacted}` → discriminated-union `{kind:…}` return shape, `Ego`→`Rxo` at `:470250`) — no published bullet, no upgrade gotcha. **MEM** changed only by a *silent removal* (the `tengu_billiard_aviary`-gated immutable-memory / `tiny_memory` experiment, `1→0` (183)→(193)) — also no published bullet; the one MEM-labeled bullet (the 2.1.186 "MEMORY.md compact reminder") is a **false delta** (byte-identical carryover from 183). Both still have depth dirs ([`../07_compact/`](../07_compact/), [`../31_auto_memory/`](../31_auto_memory/)) documenting the no-user-facing-change fact. Several other changelog lines were likewise confirmed **carryover** rather than new (the bg "stuck working" finalizer, the background-worker permission forwarding, the `/plugin` "more above" indicator, the leaked-worktree cleanup) — flagged honestly in the per-version files to prevent false-delta inflation.

> **Out of scope (changed in this window, not in the twelve themes):** the large UI / terminal / Windows reliability tail (welcome-splash overflow, permission-prompt option-number alignment, `~~strikethrough~~` literal tildes, fullscreen mouse-click, Ghostty Cmd+click, WSL/CJK paste, vim-mode search hint, …), the streaming-perf render internals, remote-control/update/share plumbing, and model-picker stale-after-`/login`.
